# Smart Calculator

A lightweight, command-line calculator built with Python to demonstrate core distributed version control concepts, branching workflows, and intentional merge conflict resolution using Git and GitHub.

---

## Features

- **Basic Arithmetic Operations**: Initial implementation provides clean calculation logic.
- **Robust Input Validation**: Handles non-numeric and edge inputs gracefully.
- **Pure Standard Library**: No external third-party dependencies required.
- **Git Demonstration Ready**: Structured to showcase feature branching, merging, and merge conflict resolution.

---

## Prerequisites

- **Python 3.8+** installed on your system.
- Terminal / PowerShell / Bash environment.

---

## Project Structure

```text
smart-calculator/
├── calculator.py       # Core calculator logic and CLI interface
├── README.md           # Project documentation and execution instructions
└── .gitignore          # Ignores bytecode, caches, and virtual environments
```

---

## Execution Instructions

1. Open your terminal and navigate to the project directory:
   ```bash
   cd smart-calculator
   ```

2. Run the calculator application using Python:
   ```bash
   python calculator.py
   ```

3. Enter two numbers when prompted to see the calculation result.
